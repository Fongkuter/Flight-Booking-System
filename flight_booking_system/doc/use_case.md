# Flight Booking System

## 1. Actors

### Customer
Khách hàng sử dụng hệ thống để tìm kiếm và đặt vé máy bay.

Các chức năng:
- Đăng ký
- Đăng nhập
- Tìm kiếm chuyến bay
- Xem chuyến bay
- Chọn chuyến bay
- Nhập thông tin hành khách
- Chọn ghế
- Chọn hành lý
- Đặt vé
- Thanh toán
- Xem vé
- Hủy vé

### Admin
Quản trị viên quản lý hệ thống.

Các chức năng:
- Đăng nhập
- Quản lý người dùng
- Quản lý sân bay
- Quản lý hãng bay
- Quản lý máy bay
- Quản lý chuyến bay
- Quản lý ghế
- Quản lý Booking
- Quản lý thanh toán
